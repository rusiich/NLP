# 🧠 NLP Projects

Проекты, реализованные в рамках изучения и применения методов обработки естественного языка (NLP).  
Задачи включают классификацию текстов, очистку данных, лемматизацию и использование трансформеров (BERT).

---

## 🔍 Основные проекты

| Название проекта | Описание | Используемые библиотеки |
|------------------|-----------|--------------------------|
| **Разметка платежей по соглашениям с регфондами** | Модель логистической регрессии, обученная на вручную размеченных строках, определяет вид финансирования работ по назначению платежа. Реализован процесс итеративной ручной валидации. Достигнута F1-метрика **99.87%**. | Python, Pandas, NumPy, Scikit-learn, NLTK, LogisticRegression, Matplotlib, Seaborn, Joblib |
| **Классификация токсичных комментариев для Викишоп** | Модель классифицирует комментарии на токсичные и нетоксичные. Реализованы два подхода — классический (TF-IDF + Logistic Regression) и с использованием трансформеров **BERT**, где достигнута F1-метрика **0.95**. | Python, Pandas, NLTK, spaCy, Pymystem3, Scikit-learn, Huggingface Transformers (BERT), Joblib |
